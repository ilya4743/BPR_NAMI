\doxysubsection{Подробное описание}
Класс для построения неориентированного прямоугольного графа 

Значение {\bfseries{width}} и {\bfseries{height}} неориентированного прямоугольного графа задают количество вершин по ширине и высоте соответственно. ~\newline
Рёбра графа связывают смежные пары вершин по горизонтали, вертикали, главной и побочной диагонали. ~\newline
На рисунке изображена схема неориентированного прямоугольного графа
