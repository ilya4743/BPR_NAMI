\doxysubsection{Подробное описание}
Класс прямоугольной матрицы расстояний 

Матрица создается на базе вектора точек (x, y). ~\newline
Значение {\bfseries{width}} задает количество элементов матрицы по ширине. ~\newline
Значение {\bfseries{height}} задает количетво элементов матрицы по высоте. ~\newline
Значение {\bfseries{step}}(шаг) отвечает за расстояние от одной точки до другой. ~\newline
Значение {\bfseries{center}} задает номер элемента матрицы, который будет считаться точкой отсчета. ~\newline
На рисунке представлена схема прямоугольной матрицы расстояний, с точкой отсчета в элементе под номером 12.
